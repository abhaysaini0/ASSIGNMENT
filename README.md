## 🌟 Overview
This repository contains a multi-page static website created for a college assignment. It is designed to demonstrate semantic page structure, form handling, and site navigation without relying on heavy frameworks. 

**🔗 [View the Live Website](https://abhaysaini0.github.io/ASSIGNMENT/)**

## ✨ Features
* **Student Registration Portal:** A fully structured application form with inputs for personal details, course selection (Web Designing, Python, Java, C), and OTP verification steps.
* **Course Information:** A dedicated section displaying available academic programs.
* **About & Contact:** Informational pages to learn about the institution and reach out for inquiries.

## 🛠️ Technologies Used
* **HTML5:** Core page structure and elements.
* **GitHub Pages:** For continuous deployment and live hosting.

## 📂 Repository Structure
* `index.html` - The main landing page.
* `regist.html` / `registration.html` - Student application and registration forms.
* `COURSES.HTML` - Detailed course listings.
* `about us.html` - Information about the college.
* `contact.html` - Contact details and forms.
* `CMR-NAAC-LOGO copy.png` - Site branding and logo assets.
